# External Inspirations

These notes identify selected ideas and primary sources from mature systems. They are not dependency
plans, compatibility claims, or specifications for `handoff` APIs.

- [LMAX Disruptor](lmax-disruptor.md)
- [Firedancer Tango](firedancer-tango.md)
- [DPDK ring library](dpdk-ring.md)

Future implementations should be organized and documented by the mechanism being studied. Use
terms such as `Disruptor-inspired`, `Firedancer-inspired`, or `DPDK-inspired` and state exactly which
property was reproduced.
